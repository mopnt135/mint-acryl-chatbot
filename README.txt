민트 아크릴샵 AI 챗봇 (내 컴퓨터 실행용)

[처음 한 번만 할 일]

1. Node.js 설치
   https://nodejs.org 에서 LTS 버전을 내려받아 설치해요.
   이미 설치되어 있으면 건너뛰어요.

2. API 키 넣기
   start.bat 을 처음 더블클릭하면 .env 파일이 만들어지고 메모장이 열려요.
   (직접 하려면 .env.example 을 복사해서 이름을 .env 로 바꿔요.)
   ANTHROPIC_API_KEY= 뒤에 내 API 키를 붙여 넣어요.
   예) ANTHROPIC_API_KEY=sk-ant-여기에키
   따옴표나 띄어쓰기 없이 넣고 저장한 뒤 메모장을 닫아요.
   API 키는 Anthropic 콘솔(console.anthropic.com)에서 만들 수 있어요.

[실행하기]

1. start.bat 을 더블클릭해요.
2. 검은 창이 뜨고 잠시 뒤 브라우저에 챗봇이 열려요.
   안 열리면 브라우저 주소창에 http://localhost:3000 을 입력해요.
3. 쓰는 동안 검은 창은 닫지 말아요. 닫으면 챗봇이 꺼져요.

[화면 구성]

아크릴 스탠드 탭
  AI가 아크릴 스탠드 상품을 안내하고, 원하면 가상 주문을 만들어요.
  주문번호로 배송 현황도 물어볼 수 있어요.
  AI 답변 아래의 좋아요, 아쉬워요, 신고하기 버튼으로 의견을 남길 수 있어요.

관리자 탭
  상품, 재고, 주문, 배송, 아크릴 탭 설정을 보고 고칠 수 있어요.
  데이터 내보내기로 백업 파일을 만들 수 있어요.
  대화 기록: 사용자 대화를 보고 답변마다 피드백을 남겨요.
  신고 통계: 사용자가 신고한 답변을 사유별, 사용자별로 봐요.
  답변 지침: 피드백으로 만든 지침을 켜고 끄고 고쳐요. 켜진 지침은 다음 답변부터 AI가 따라요.
  대화 기록은 이 브라우저에만 저장되니 가끔 "기록 내보내기"로 백업하세요.

[파일 설명]

  start.bat   챗봇을 켜는 파일
  .env           API 키와 설정 (다른 사람에게 보내지 말 것)
  .env.example   .env 견본 (키 없음)
  server.js      챗봇 서버 프로그램
  public         화면 파일
  seed.json      처음 가상 데이터
  data.json      실행 후 생기는 실제 저장 데이터

[문제가 생기면]

  "API 키가 없어요"        .env 에 키를 넣고 검은 창을 닫았다가 다시 실행해요.
  "API 키가 올바르지 않아요" 키를 다시 복사해서 넣어요.
  "모델 이름을 쓸 수 없어요"  .env 의 ANTHROPIC_MODEL 을 Anthropic 문서의 최신 모델 이름으로 바꿔요.
  "포트를 이미 쓰고 있어요"  이미 켜진 검은 창이 있는지 확인하거나 .env 의 PORT 를 3001 등으로 바꿔요.

[주의]

  AI를 쓸 때마다 Anthropic API 요금이 나와요.
  모든 주문과 배송은 연습용 가상 데이터예요. 실제 고객 정보를 넣지 마세요.
  이 프로그램은 내 컴퓨터에서만 접속돼요. 다른 사람은 들어올 수 없어요.
